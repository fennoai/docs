# FAQ

<Details open>
<Summary>Is FennoAI free to use?</Summary>

FennoAI itself is completely free. You just need an AI model provider account.
We currently integrate with 
[Fenno API](https://api.fenno.ai),
ready to use out of the box.

</Details>

<Details>
<Summary>Does FennoAI work with private repositories?</Summary>

Yes. FennoAI works with private repositories on GitHub.

</Details>

<Details>
<Summary>Is my code used for AI training?</Summary>

FennoAI does not use your code to train any AI models.

</Details>

<Details>
<Summary>Which programming languages does FennoAI support?</Summary>

Powered by AI models, FennoAI supports every programming language.

</Details>

<Details>
<Summary>Does FennoAI only work with GitHub?</Summary>

Yes. FennoAI integrates with GitHub issues and pull requests.

</Details>

<Details>
<Summary>Why doesn't my organization appear on the Settings page?</Summary>

If you've installed the FennoAI GitHub App on an organization but it doesn't
show up on the **Settings** page, it's likely because the app has recently
requested new permissions (e.g. **Organization members — Read-only**) that
your organization has not yet accepted. Go to your organization's **Settings →
GitHub Apps → FennoAI**, review and accept the updated permissions, and the
organization will appear on the Settings page.

</Details>

<Details>
<Summary>Which AI models are supported?</Summary>

Claude, DeepSeek, Gemini, MiniMax, Zhipu, Kimi, and more. With a Fenno API Key you can access all of them with a single key. See [Model
Selection →](/en/ai/model-selection) for details.

</Details>

<Details>
<Summary>How do I report a bug or request a feature?</Summary>

Report documentation issues or suggestions in [GitHub Issues](https://github.com/fennoai/docs/issues/new), or join the [Discord community](https://discord.gg/9HFMKz4qrg). Remove API keys and private project content from public reports.

</Details>
