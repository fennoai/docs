# Quick Start

The fastest way to get started is through the **FennoAI GitHub App** — no server setup, no configuration files.

## GitHub App (Recommended)

<Steps>

### Install the GitHub App

Visit [github.com/apps/fennoai](https://github.com/apps/fennoai) and click **Install**. Select the repositories you want FennoAI to work in.

### Open an Issue or PR

Go to any Issue or PR in your repository.

### Mention FennoAI

Leave a comment mentioning `@fennoai`:

```text
@fennoai hello, can you analyze this repository structure?
```

### Wait for the response

FennoAI replies in the same thread. You'll see its progress as it reads the repository and works on the request.

### Try a real task

Once you've confirmed it's working, try a meaningful task:

```text
/code fix the bug described in this issue
```

That's it. FennoAI will clone your repo, write the fix, and open a PR for your review.

</Steps>
