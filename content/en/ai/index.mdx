# FennoAI

FennoAI is a coding Agent that works inside GitHub. Describe a task in an issue or pull request and let it inspect the repository, write code, run tests and propose changes without moving context between tools.

## How it works

| Entry point | Typical work |
| --- | --- |
| GitHub issue | Investigate a problem, plan a fix and open a pull request |
| GitHub pull request | Review changes, address feedback and improve an implementation |
| Scheduled task | Produce summaries, check code and dependencies, maintain documentation |

## Models and configuration

Use a **Fenno API key** for models available to your account, or configure another provider. FennoAI supports providers including Claude, DeepSeek, Gemini, MiniMax, Zhipu and Kimi. Specific models and capabilities depend on your account and configuration.

- [Model selection](/en/ai/model-selection): choose models for different tasks.
- [Repository configuration](/en/ai/configuration): set repository defaults in `.fennoai.yml`.
- [Fenno API documentation](/en/api): explore model endpoints, authentication and tool integrations.

<Callout type="info">
  Agent output still needs review. Check code changes, test results and permissions before merging. Start with a test repository and a small, well-scoped task.
</Callout>
