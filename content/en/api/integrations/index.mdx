# Tool integrations

Most tools need three settings: **API address, Fenno API key, and model ID**. Choose a guide for your tool before configuring it: addresses are not interchangeable between protocols.

## Before you start

1. Create an API key in the [Fenno console](https://api.fenno.ai) and check your available quota.
2. Copy an **exact model ID** from the console or model list. Do not use a display name or invent a provider prefix.
3. Check protocol and capability support. Codex needs Responses; coding agents also need streaming and tool calling.
4. Back up existing configuration. Use a new conversation and a simple prompt before allowing changes to an important project.

<Callout type="warning">
  A tool subscription and Fenno API usage are billed separately. Bringing your own key does not unlock every paid client feature or make requests free.
</Callout>

## Verify the actual connection

Send “Reply with OK only”, then match the request time, model and usage in the Fenno console. **A model claiming to use Fenno is not proof of routing**.

Test streaming, image input and tool calling separately after the text request works. A working connection does not imply support for every capability. See the [general checklist](/en/api/integrations/others) and [errors and retries](/en/api/errors).
