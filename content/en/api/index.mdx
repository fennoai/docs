# Fenno API

Fenno API provides a common entry point for models available to your account through OpenAI-compatible,
Anthropic Messages and Gemini protocols. Configure the endpoint, credentials and exact model ID,
then verify the capabilities required by your application.

## Base URL

| Protocol | Base URL |
| --- | --- |
| OpenAI compatible | `https://api.fenno.ai/v1` |
| Anthropic native | `https://api.fenno.ai` |
| Gemini native | `https://api.fenno.ai` |

<Callout type="info">
  Native Anthropic and Gemini SDKs append their own versioned path (`/v1/messages`,
  `/v1beta/models/*`), so point them at the host without `/v1`. OpenAI-compatible clients expect
  the version in the base URL, so use `https://api.fenno.ai/v1`.
</Callout>

## Supported protocols

| Protocol | Typical callers | Path prefix |
| --- | --- | --- |
| OpenAI compatible | OpenAI SDK, Codex, Cline, OpenCode, LangChain | `/v1/*` |
| Anthropic native | Claude Code, Anthropic SDK | `/v1/messages` |
| Gemini native | Gemini CLI, Google GenAI SDK | `/v1beta/models/*` |
