## Base URLs

| Client | Base URL | Example final path |
| --- | --- | --- |
| OpenAI SDK | `https://api.fenno.ai/v1` | `/v1/chat/completions` |
| Anthropic SDK | `https://api.fenno.ai` | `/v1/messages` |
| Google GenAI SDK | `https://api.fenno.ai` | `/v1beta/models/{model}:generateContent` |

An endpoint accepting a protocol does not guarantee every model supports every upstream feature. Use exact IDs available to your account, then verify the requested modality, tool support and optional fields. Examples use environment variables rather than a permanently maintained model list.

This reference does not imply support for upstream-hosted storage, batch jobs, built-in tools, file-management APIs or Agent APIs that are not documented here. Responses are simplified examples where stated; model-specific fields may vary.

## Common conventions

- Send credentials using the [authentication headers](/en/reference/authentication).
- JSON requests use `Content-Type: application/json`; image edits use multipart form data.
- Handle errors using status and structured fields, not literal matching of human-readable messages.
- Treat returned request IDs, usage and rate-limit headers as optional unless the endpoint explicitly requires them.
- API examples require your own credentials and incur normal usage; documentation builds do not execute them.

See the [error formats](/en/reference/errors), [streaming guide](/en/api/guides/streaming) and [model capabilities](/en/api/models).
