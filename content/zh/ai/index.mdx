# FennoAI

FennoAI 是直接参与 GitHub 工作流的编程 Agent。在 Issue 或 Pull Request 中描述需求，让它理解仓库、编写代码、运行测试并发起修改，无需在多个工具间反复搬运上下文。

## 工作方式

| 入口 | 常见任务 |
| --- | --- |
| GitHub Issue | 分析问题、制定方案、实现修复并发起 PR |
| GitHub Pull Request | 审查差异、响应反馈、改进现有实现 |
| 定时任务 | 生成摘要、检查代码与依赖、整理文档 |

## 模型与配置

使用 **Fenno API Key** 访问账户可用的模型，也可以按配置接入其他提供方。FennoAI 支持 Claude、DeepSeek、Gemini、MiniMax、智谱、Kimi 等模型提供方；具体模型与能力以当前账户和配置为准。

- [模型切换](/zh/ai/model-selection)：为不同任务选择模型。
- [仓库级配置](/zh/ai/configuration)：通过 `.fennoai.yml` 设置仓库默认行为。
- [Fenno API 文档](/zh/api)：查看模型接口、鉴权与工具接入。

<Callout type="info">
  Agent 的输出仍需审查。合并前请检查代码差异、测试结果和权限范围；首次尝试可从测试仓库和范围明确的小任务开始。
</Callout>
