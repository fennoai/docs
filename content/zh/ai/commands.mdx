# 命令参考

FennoAI 支持斜杠命令，用于目标明确的具体任务。每个命令针对特定场景设计 —— 选对命令，得到更精准的结果。

## 快速参考

| 命令        | 使用位置     | 作用               |
| ----------- | ------------ | ------------------ |
| `/code`     | Issues / PRs | 编写代码并提 PR    |
| `/plan`     | Issues       | 生成实施方案       |
| `/review`   | PRs          | 全面的代码审查     |
| `/simplify` | PRs          | 简化和重构 PR 代码 |
| `/compact`  | Issues / PRs | 汇总进度并清理评论 |
| `/close`    | Issues / PRs | 关闭 Issue 或 PR   |

---

## `/code` — 编写代码

**一句话说明**：把需求描述直接变成一个真实的 Pull Request。

**什么时候用**：

- Issue 描述清楚了，想让 AI 直接写实现代码
- PR 里已有 Review 意见，想让 FennoAI 根据意见修改代码

**用法示例**：

```text
/code

搜索接口不支持按日期范围筛选。
请给 GET /api/search 添加 `from` 和 `to` 查询参数。
```

提交后，FennoAI 会克隆仓库、编写代码、运行测试，并提交一个 PR 供你 Review。

---

## `/plan` — 先规划再动手

**一句话说明**：在写代码之前，先生成一份实施方案。

**什么时候用**：

- 需求比较复杂，团队需要在动手之前先对齐方案
- 技术路径不确定，想让 AI 分析后给出建议

**用法示例**：

```text
/plan

需要从 JWT 迁移到基于 Session 的认证。
现有的 User 模型需要保持兼容。
请列出实施思路和受影响的文件。
```

FennoAI 返回：架构决策、逐文件变更列表、迁移策略、风险说明。团队确认方案后，再用 `/code` 实现。

---

## `/review` — 代码审查

**一句话说明**：让 AI 对 PR 做一次完整的 Code Review。

**什么时候用**：

- PR 准备好了，想在人工审查前先做一轮 AI 检查
- 想在合并前发现安全漏洞、性能问题或逻辑 Bug

**用法示例**：

```text
/review
```

或聚焦某个方面：

```text
/review 重点关注数据库事务处理。
```

FennoAI 审查 diff 中的 Bug、安全漏洞、性能问题和代码质量，并以行内评论形式给出反馈。

---

## `/simplify` — 重构精简

**一句话说明**：精简 PR 中过于复杂的代码。

**什么时候用**：

- PR 里的代码能用，但太啰嗦或逻辑难以理解
- 某个函数太长了，需要拆分

**用法示例**：

```text
/simplify PaymentProcessor 类太大了，
请把它拆成更小、职责单一的函数。
```

FennoAI 重写代码，使其更清晰，并将改动推送到该 PR 的分支。

---

## `/compact` — 汇总与重置

**一句话说明**：对 Issue 或 PR 的当前状态做一次汇总，并清理机器人评论。

**什么时候用**：

- Issue 或 PR 评论太多，现状不清晰
- 经过多轮 AI 交互后，希望重置上下文、重新来过

**用法示例**：

```text
/compact
```

FennoAI 生成一条汇总评论，说明已决定的事项、待解决的问题和下一步计划。之前的机器人评论会被清理。

---

## `/close` — 关闭

**一句话说明**：让 AI 确认 Issue 已解决并关闭它。

**什么时候用**：

- Issue 已被某个合并的 PR 解决，想让 AI 确认后关闭
- PR 不再需要，直接关闭

**用法示例**：

```text
/close 修复已在 PR #234 中合并。
```

FennoAI 验证上下文后，关闭 Issue 或 PR 并留下汇总评论。
