# 快速开始

最快的上手方式是通过 **FennoAI GitHub App** —— 无需搭建服务器，无需配置文件。

## GitHub App（推荐）

<Steps>

### 安装 GitHub App

访问 [github.com/apps/fennoai](https://github.com/apps/fennoai)，点击 **Install**，选择要使用 FennoAI 的仓库。

### 打开一个 Issue 或 PR

进入你仓库中的任意 Issue 或 PR。

### @ 提及 FennoAI

发表一条包含 `@fennoai` 的评论：

```text
@fennoai 你好，帮我分析一下这个仓库的结构
```

### 等待响应

FennoAI 会在同一评论线程中回复，你可以查看它读取仓库和执行任务的进展。

### 尝试一个真实任务

确认它正常工作后，尝试一个有意义的任务：

```text
/code 修复这个 Issue 中描述的 Bug
```

FennoAI 会克隆仓库，编写修复代码，并提交一个 PR 供你 Review。

</Steps>
