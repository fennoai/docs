## A. 服务

### 概述

Fenno 向客户提供多种 AI 相关产品与服务，具体以客户订购时约定为准。客户可通过 Fenno 提供的接口、插件或其他方式使用服务。

在不限制前述通用描述的前提下，Fenno 部分服务可能涉及读取和分析客户提供的代码文件、项目结构或其他上下文信息，以生成与客户需求相关的建议和输出。此类服务的具体功能范围、使用方式及数据处理细节，以产品页面说明或双方另行约定为准。

## B. 客户内容

在各方之间以及在适用法律允许的范围内，Fenno 同意客户：

1. 保留其输入的所有权利；
2. 拥有其输出。

Fenno 放弃其根据这些条款收到的客户内容的任何权利。在客户遵守这些条款的前提下，Fenno 特此将其在输出中的权利、所有权和利益（如果有）转让给客户。

Fenno 不会使用来自服务的客户内容（包括上下文信息）训练模型。

“输入”是指：

1. 对于 AI 编程助手：客户或其用户向服务提交的内容，以及为提供代码生成、补全、解释等服务而从客户开发环境中读取的上下文信息；
2. 对于大模型 API 服务：客户通过 API 向服务提交的内容。

“输出”是指服务针对输入生成的响应，包括但不限于生成的代码片段、补全建议、解释文本等。

输入和输出统称为“客户内容”。

“上下文信息”是指服务为生成输出而从客户开发环境中读取的代码文件、项目结构、仓库内容、配置及其他上下文。上下文信息属于输入的一部分。

对于 AI 编程助手服务，客户承认并同意，为提供实时代码补全和建议，服务需要读取和临时处理上下文信息。我方承诺：

1. 仅将上下文信息用于实时生成与客户项目相关的代码建议和输出；
2. 不将上下文信息用于任何其他目的；
3. 在生成输出后，不会保留上下文信息的持久副本，但为提供服务所必需的技术缓存除外；
4. 不会将上下文信息用于训练或改进模型。
