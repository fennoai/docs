## 基础地址

| 客户端 | Base URL | 最终路径示例 |
| --- | --- | --- |
| OpenAI SDK | `https://api.fenno.ai/v1` | `/v1/chat/completions` |
| Anthropic SDK | `https://api.fenno.ai` | `/v1/messages` |
| Google GenAI SDK | `https://api.fenno.ai` | `/v1beta/models/{model}:generateContent` |

支持某种协议，不代表所有模型都支持上游的全部功能。先使用账户实际可用的精确模型 ID，再验证输入类型、工具能力与可选参数。示例使用环境变量，不维护永久有效的静态模型清单。

本栏没有承诺支持未明确列出的上游托管存储、批处理、内置工具、文件管理或 Agent API。注明简化的响应仅用于解释结构，模型特有字段可能不同。

## 通用约定

- 按[鉴权参考](/zh/reference/authentication)发送认证 Header。
- JSON 请求使用 `Content-Type: application/json`；图片编辑使用 multipart 表单。
- 通过状态码和结构化字段处理错误，不依赖错误消息的固定措辞。
- 除端点另有要求外，请求 ID、usage 与限流 Header 都应兼容缺失。
- 示例需要自备密钥，并产生正常用量；文档构建不会实际执行这些 API 请求。
