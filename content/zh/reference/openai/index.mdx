# OpenAI 兼容 API

OpenAI SDK 的 Base URL 使用 `https://api.fenno.ai/v1`，并明确传入 Fenno Key。下表是原始 HTTP 完整路径，已经包含 `/v1`，不要重复拼接。

| 方法 | 完整路径 | 参考 |
| --- | --- | --- |
| POST | `/v1/chat/completions` | [Chat Completions](/zh/reference/openai/chat-completions) |
| POST | `/v1/responses` | [Responses](/zh/reference/openai/responses) |
| POST | `/v1/embeddings` | [Embeddings](/zh/reference/openai/embeddings) |
| POST | `/v1/images/generations` | [Images](/zh/reference/openai/images) |
| POST | `/v1/images/edits` | [Images](/zh/reference/openai/images) |
| GET | `/v1/models` | [模型查询](/zh/reference/openai/models) |
| GET | `/v1/models/{model}` | [模型查询](/zh/reference/openai/models) |

## 鉴权

```http
Authorization: Bearer <FENNO_API_KEY>
Content-Type: application/json
```

上传图片时使用 multipart 表单，而不是 JSON。

## 选择对话接口

Chat Completions 接收 `messages`、返回 `choices`；Responses 接收 `input`、返回类型化 `output` 项。二者的工具定义、输出限制、JSON Schema 字段和流式事件不能直接互换。

协议兼容不意味着支持 OpenAI 官方的所有服务和模型选项。SDK 提供了某个方法，也不能据此推断 Fenno 已提供托管工具、响应持久化查询、后台任务或文件 API。

继续阅读 [OpenAI SDK 接入](/zh/api/integrations/openai-sdk)、[结构化输出](/zh/api/guides/structured-output)和[官方 API 文档](https://developers.openai.com/api/reference)。
