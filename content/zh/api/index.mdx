# Fenno API

Fenno API是一个统一的 AI 模型接入网关：用一个 API Key 接入 GPT、Claude、Gemini 等主流模型，兼容 OpenAI、Anthropic、Gemini 三套协议，已有工具和 SDK 通常只需要替换 `base_url` 与 `api_key`。

## 基础地址

所有请求统一使用以下 Base URL：

```text
https://api.fenno.ai/v1
```

<Callout type="info">
  兼容层路径与官方协议保持一致：`/v1/chat/completions`、`/v1/responses`、
  `/v1/messages`、`/v1beta/models/*` 等，把原有的 `base_url` 换成上面的地址即可。
</Callout>

## 支持的协议

| 协议 | 典型调用方 | 端点前缀 |
| --- | --- | --- |
| OpenAI 兼容 | OpenAI SDK、Codex、Cline、OpenCode、LangChain | `/v1/*` |
| Anthropic 原生 | Claude Code、Anthropic SDK | `/v1/messages` |
| Gemini 原生 | Gemini CLI、Google GenAI SDK | `/v1beta/models/*` |
