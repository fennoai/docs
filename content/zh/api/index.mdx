## 基础地址

| 协议 | Base URL |
| --- | --- |
| OpenAI 兼容 | `https://api.fenno.ai/v1` |
| Anthropic 原生 | `https://api.fenno.ai` |
| Gemini 原生 | `https://api.fenno.ai` |

<Callout type="info">
  Anthropic 与 Gemini 原生 SDK 会自行拼接版本路径（`/v1/messages`、`/v1beta/models/*`），
  请只填写不带 `/v1` 的主机地址；OpenAI 兼容客户端则需要在 Base URL 中包含版本号，
  使用 `https://api.fenno.ai/v1`。
</Callout>

## 支持的协议

| 协议 | 典型调用方 | 端点前缀 |
| --- | --- | --- |
| OpenAI 兼容 | OpenAI SDK、Codex、Cline、OpenCode、LangChain | `/v1/*` |
| Anthropic 原生 | Claude Code、Anthropic SDK | `/v1/messages` |
| Gemini 原生 | Gemini CLI、Google GenAI SDK | `/v1beta/models/*` |
