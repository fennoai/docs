# 工具接入

在已有工具中使用 Fenno，通常需要填写三项：**API 地址、Fenno API Key、模型 ID**。先选择工具，再按对应协议配置；不要把不同工具的地址直接互换。

## 接入前准备

1. 在 [Fenno 控制台](https://api.fenno.ai) 创建 API Key，确认账户可用额度。
2. 从控制台或模型列表复制**精确模型 ID**；不要使用展示名称，也不要自行添加厂商前缀。
3. 确认模型支持工具所需的协议和能力。Codex 需要 Responses；编程工具还需要流式输出与工具调用。
4. 备份已有配置。首次验证用新会话和简单提示词，不要直接在重要项目里执行修改。

<Callout type="warning">
  第三方工具的订阅和 Fenno API 用量分别计费。配置了自己的 API Key，不代表工具的所有付费功能都会开放，也不代表请求免费。
</Callout>

## 如何确认真的接通

先发送“只回复 OK”，再在 Fenno 控制台核对请求时间、模型和用量。**模型自述“我使用了 Fenno”不是验证依据**。

文本成功后，再分别测试流式输出、图片输入或工具调用。基础连接正常不代表每种模型能力都可用。遇到问题先看[通用排错清单](/zh/api/integrations/others)与[错误与重试](/zh/api/errors)。
