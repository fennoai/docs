# Anthropic 原生 API

Base URL：`https://api.fenno.ai`（SDK 会自动拼接 `/v1/messages`）。
适用于 Claude Code、Anthropic SDK 以及任何直接调用 Messages API 的客户端。

## 端点一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/v1/messages` | 创建消息 |
| POST | `/v1/messages/count_tokens` | 预估输入 token |
| GET | `/v1/models` | 模型列表 |
| GET | `/v1/models/{model}` | 单个模型信息 |

## 认证

```http
x-api-key: $FENNO_API_KEY
anthropic-version: 2023-06-01
content-type: application/json
```

## 基本调用

```bash
curl https://api.fenno.ai/v1/messages \
  -H "x-api-key: $FENNO_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-sonnet-4-5",
    "max_tokens": 512,
    "messages": [{"role": "user", "content": "用一句话总结这篇 PR 的风险"}]
  }'
```

```python
from anthropic import Anthropic

client = Anthropic(base_url="https://api.fenno.ai", api_key="<FENNO_API_KEY>")

msg = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=512,
    messages=[{"role": "user", "content": "用一句话总结这篇 PR 的风险"}],
)
print(msg.content[0].text)
```

## 流式响应

事件顺序与 Anthropic 官方一致：

```text
message_start → content_block_start → content_block_delta*
→ content_block_stop → message_delta → message_stop
```

处理时请按事件类型判断，不要依赖单一文本增量假设。

## 内容块

`content` 支持字符串或内容块数组，常见块类型：

| 类型 | 用途 |
| --- | --- |
| `text` | 纯文本 |
| `image` | 图片输入（base64 或 URL） |
| `document` | PDF 等文档输入 |
| `tool_use` / `tool_result` | 工具调用与结果回传 |
| `thinking` | 推理内容（模型支持时） |

<Callout type="info">
  工具调用与思考块的结构随模型能力不同而变化。跨模型迁移时，建议只消费你真正需要的块类型，
  并在代码里做类型兜底。
</Callout>

## 与 OpenAI 协议的差异

- 系统提示使用顶层 `system` 字段，而不是 `messages` 中的 system 角色。
- `max_tokens` 必填。
- 工具定义使用 `input_schema`（JSON Schema），调用结果通过 `tool_result` 内容块回传。
- 停止原因字段为 `stop_reason`，取值为 `end_turn`、`max_tokens`、`tool_use` 等。
